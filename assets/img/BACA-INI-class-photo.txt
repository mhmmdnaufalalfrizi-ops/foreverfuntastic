FOTO LATAR BANNER STATISTIK SISWA (halaman Tentang)
=====================================================

Taruh 1 file foto bareng sekelas di sini dengan nama PERSIS:
    class-photo.jpg

Banner "44 Students / 32 Girls / 12 Boys" di halaman tentang.html akan
otomatis memakai foto ini sebagai latar belakang (dengan overlay gelap
supaya teks tetap kebaca).

Kalau belum ada fotonya, banner tetap tampil normal dengan warna gelap
polos sebagai latar — jadi aman dibuka meski file ini belum diisi.

Mau pakai nama file lain? Ubah juga path-nya di:
  assets/css/style.css -> cari ".stats-banner" -> ganti "class-photo.jpg"
